PROJECTS

1. E-Portfolio Website (Frontend)

I designed and developed this personal e-portfolio website using HTML AND CSS to showcase my projects, skills, and achievements. The project demonstrates my ability to build a clean and well-structured webpage using HTML, apply responsive layouts and visual styling with CSS using concepts like flexbox,grid,floats,media queries etc. Through this project, I strengthened my understanding of front-end web development, UI design principles, and responsive design for different screen sizes.

2. Blood Bank Management System (Backend)

I developed the backend of a Blood Bank Management System using PYTHON AND MYSQL to manage blood donation and distribution efficiently. The system supports core functionalities such as placing blood orders, registering blood donations, and viewing or searching the availability of different blood groups. It features real-time database updates, ensuring that blood stock levels are automatically adjusted whenever blood is donated or ordered. This project strengthened my skills in backend development, database design, SQL queries, and maintaining data consistency in real-world applications.

3. In House Sound Amplifier (Hardware Project)

I designed and built an in-house sound amplifier capable of delivering high-quality, high-volume audio output. The system takes audio input from a phone or laptop via a 3.5 mm jack, processes it through a TPA3116D2 audio amplifier module, and outputs amplified sound through an external speaker. It is powered using a 220 V AC supply, with a 24 V power module acting as a rectifier to provide stable DC power to the circuit. This project enhanced my understanding of analog electronics, power supply design, signal amplification, and practical hardware integration, while demonstrating my ability to build reliable real-world audio systems with excellent sound quality.
